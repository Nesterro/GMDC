# GMDC - Revit 2025 Ribbon Add-in

**GMDC** — это современный плагин (надстройка) для Autodesk Revit 2025, написанный на C# (.NET 8.0). Он предоставляет инженерам и проектировщикам три автоматизированных инструмента, объединенных в общую ленту (Ribbon Tab) с минималистичным и интуитивно понятным интерфейсом:

1. **Экспорт в Excel** — экспорт спецификаций/ведомостей модели с расширенным форматированием.
2. **Наименование лотков** — автоматическое заполнение параметров лотков по шаблону.
3. **Расстановка крепежа** — автоматическое размещение подвесов и опор по правилам зависимости шага от ширины кабельного лотка.

## ⚙️ Установка и Компиляция

### Шаг 1: Сборка плагина
Для сборки проекта требуется **.NET 8.0 SDK**. Откройте терминал в папке проекта и выполните команду:
```bash
dotnet build -c Release
```
После успешного билда в папке `bin/x64/Release/net8.0-windows/` будут созданы библиотека `GMDC.dll` и сопутствующие зависимости (включая `ClosedXML.dll`).

### Шаг 2: Установка в Revit
1. Перейдите в системную папку надстроек Revit 2025:
   `C:\Users\<Имя_Пользователя>\AppData\Roaming\Autodesk\Revit\Addins\2025\`
2. Скопируйте туда файл **`GMDC.addin`** из корня проекта.
3. Создайте в этой папке подпапку с именем **`GMDC`** и скопируйте в неё все файлы сборки из папки `bin/x64/Release/net8.0-windows/`.
4. Запустите Revit 2025. При запросе подтверждения загрузки выберите **"Всегда загружать"** (Always Load).

## 📖 Инструкция пользователя

После запуска Revit на панели вкладок появится новая вкладка **GMDC** с тремя инструментами.

### 1. Экспорт в Excel
Инструмент предназначен для пакетной выгрузки спецификаций Revit в файлы формата `.xlsx` с автоматическим форматированием.

*   **Выбор таблиц**: В левой части окна отображается список всех спецификаций проекта. Используйте поле поиска для фильтрации по имени. Отметьте нужные таблицы флажками. Вы можете использовать кнопки «Выбрать все» или «Снять выделение».
*   **Режим сохранения**:
    *   *В один файл*: Экспортирует все выбранные таблицы на отдельные листы одного Excel-файла.
    *   *В разные файлы*: Экспортирует каждую выбранную спецификацию в отдельный файл `.xlsx` в выбранной папке.
*   **Путь сохранения**: Нажмите кнопку «Обзор...» и укажите целевой файл или папку.
*   **Форматирование**:
    *   Флажок «Автоподбор ширины» предотвратит усечение текста или появление ошибок `###`.
    *   Вы можете настроить цвет шапки таблицы: Фирменный зеленый GMDC (`#3bb700`), Темно-серый, Светло-серый или Без заливки.
    *   Доступны регулировка размера шрифта шапки и выбор шрифта всей таблицы (Arial, Calibri и др.).
*   **Конфигурация**: Нажмите «Сохранить конфиг», чтобы сохранить текущие настройки форматирования и пути. При следующем открытии они загрузятся автоматически (или нажмите «Загрузить конфиг»).
*   **Запуск**: Нажмите кнопку «Экспорт». После успешного экспорта появится уведомление с количеством выгруженных таблиц.

### 2. Наименование лотков
Инструмент заполняет выбранный текстовый параметр лотков по динамическому шаблону на основе свойств и параметров элементов.

*   **Область обработки**: Выберите область действия («Выбранные лотки», «Лотки на активном виде» или «Все лотки в проекте»). Если в Revit ничего не выделено, опция «Выбранные» будет автоматически отключена.
*   **Целевой параметр**: Выберите из списка или **введите вручную** любой текстовый параметр для записи (например, `Comments` (Комментарии), `Mark` (Маркировка) или `ADSK_Наименование`). Список предустановлен стандартными BIM-параметрами (включая `ADSK_Наименование`) для вашего удобства.
*   **Конструктор шаблона**:
    *   В левой части отображается список доступных параметров лотка (включая геометрические: Ширина, Высота, Размер, Имя типа).
    *   Дважды щелкните по любому параметру, чтобы вставить его токен в текстовое поле шаблона (например, `{Width}` или `{Type Name}`).
    *   Добавьте произвольный текст. Пример шаблона: `Лоток кабельный листовой {Width}x{Height} мм (тип {Type Name})`.
*   **Предварительный просмотр**: По мере ввода шаблона в окне предпросмотра отображается реальное значение на примере первого лотка из модели.
*   **Конфигурация**: Шаблоны можно сохранять и загружать с помощью кнопок в нижней панели.
*   **Запуск**: Нажмите «Запустить». Плагин откроет транзакцию Revit и запишет сформированные имена в выбранный параметр.

### 3. Расстановка крепежа
Инструмент расставляет кронштейны или подвесы (семейства категории «Обобщенная модель») по оси кабельных лотков с шагом, зависящим от ширины лотка.

*   **Семейство крепления**: Выберите загруженное семейство и типоразмер крепления из выпадающего списка.
*   **Параметры отступов**:
    *   *Отступ от начала/конца (мм)*: Расстояние от торцов лотка до первого и последнего крепления (чтобы избежать наложения на соединители и фитинги). По умолчанию: 300 мм.
    *   *Смещение по высоте (мм)*: Позволяет сместить точку вставки крепления вверх или вниз относительно низа лотка.
    *   *Поворот семейства*: Угол дополнительного поворота (0°, 90°, 180°, 270°) вокруг вертикальной оси. Помогает правильно сориентировать крепление относительно лотка.
*   **Правила шага расстановки**:
    *   В правой таблице задаются диапазоны ширины лотка и соответствующий шаг крепежа.
    *   По умолчанию настроены 3 стандартных правила:
        *   Ширина до 200 мм $\rightarrow$ шаг 2000 мм.
        *   Ширина до 400 мм $\rightarrow$ шаг 1500 мм.
        *   Ширина более 400 мм $\rightarrow$ шаг 1200 мм.
    *   Используйте кнопки «Добавить строку» и «Удалить строку» для настройки собственных шагов.
*   **Алгоритм**: Плагин рассчитывает длину лотка, вычитает начальный/конечный отступы и равномерно распределяет крепления по длине с шагом, не превышающим заданное правило. Каждое крепление автоматически поворачивается по направлению лотка и привязывается к соответствующему Уровню (Level).
*   **Запуск**: Выберите область расстановки и нажмите «Расставить».
